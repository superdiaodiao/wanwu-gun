# 万物皆可滚 · 女娲补天

女娲补天 ×《块魂》的同人 3D 网页小游戏。

女娲炼五色石炼嗨了，一锤子把天捅了个窟窿。你是她捏的小泥人，推着一颗 6 厘米的五色石，从瓜子、麻将牌滚起——猫、广场舞大妈、外卖小哥、公交车、居民楼、明珠塔、高铁，最后连山带云一起滚上天，去把窟窿补上。

**在线试玩：<https://superdiaodiao.github.io/wanwu-gun/>**

也可以直接下载仓库根目录的 [`index.html`](index.html)，用 Chrome / Edge / Safari 双击打开就能玩。

## 怎么玩

- <kbd>W</kbd>（或 ↑）往前滚，<kbd>A</kbd> <kbd>D</kbd>（← →）转弯：轻点转一点，按住越转越快；<kbd>S</kbd>（↓）掉头，镜头跟着转过来。<kbd>空格</kbd> 冲刺，<kbd>C</kbd> 切镜头，<kbd>Esc</kbd> 暂停（暂停时看全图），按住鼠标拖动转镜头。
- 手机上左手用左半边屏幕当摇杆，往哪推球就往哪滚：稍微偏一点只是轻轻拐弯，推到正侧面才直接往那边滚；推回正上方，球照现在的方向继续滚，镜头自己转到球后面；往回拉会掉头。右手在「冲」上方左右滑动转镜头（两只手可以同时用；还没用过的话，一直侧推摇杆转弯时那里会出现手指滑动的提示），右下的「冲」是冲刺。竖着拿手机时画面整体往上挪，球和推球的小人在屏幕中间、拇指上方，不会被手挡住。第一次玩会提示左手、右手分别怎么操作，暂停菜单里的「操作说明」可以再看一遍。画面卡的话会自动降低分辨率，也可以在开始页把「画质」调成低。开始页的「省电」（手机上默认打开）每秒画 30 帧而不是 60 帧，玩久了手机不容易发烫；想要更顺滑可以关掉（手机上关着省电玩完一局，结算页会提醒一句）。
- 手机开着静音也有声音（iPhone 的静音键平时会把网页游戏的声音也关掉）；不想出声就点右下角的喇叭。
- 比球小的东西一碰就粘上，球随之长大；比球大的会挡住你——轻轻弹开，提示还差多少，等长大了再来。平时撞一下不会掉东西，只有冲刺撞上才会掉。
- **边缘发金光的能滚，身上带红色斜纹的还太大**，老远就标出来了，先绕开；正前方快要撞上的东西不管多大都会闪红纹（大房子、大树只闪要撞的那一块），在屏幕外的话屏幕边上会亮红色感叹号。附近最值钱的几样会闪一闪。一口气接着滚就是「连滚」，连得越长长得越快（最多 +40%）。每到一个目标尺寸会告诉你现在又能滚起哪些东西。后期附近要是都滚不动了，停几秒球边上会出现金色箭头，指向最近一片能滚的东西。
- **补天要多大**：天上的窟窿得一块 **50 米**的补天石才补得满（快到时仪表上写「补天 50 m」）；不够的话只能补上一部分。
- **限时补天**：6 分钟，从上午滚到天黑。时间一到，球飞上天去补窟窿，女娲按大小给你封称号（小泥丸 → 泥球 → 石球 → 巨石 → 补天石 → 五色神石 → 开天辟地）。滚到 50 米后也可以点「提前补天」不等时间到。
- **自由滚**：不限时。滚到 50 米后出现「去补天」（电脑上在屏幕上方，手机上在小地图下面），随时可以点（也可以从暂停菜单去）；城里都滚空了女娲会提醒你。
- 右上角的小地图跟着镜头转、随球变大拉远：金点是现在能滚起的，红的还太大，深色是更大的。点一下小地图（或暂停）看全图和走过的路。
- **女娲的心愿**：每局开始女娲随机提三个心愿，一个前期的（滚起 3 只小黄鸭、凑齐一万八筒红中发财……）、一个中期的（滚起 3 只猫、把广场舞音箱滚走、把公交车滚上来……）、一个后期的（把宝塔 / 摩天轮 / 高铁滚上来、滚起一座山、6 分钟内长到 500 米……）。左上角的星星是进度，点它看心愿清单；有进展时星星旁边悄悄显示一下（如「猫 2/3」），每达成一个亮一颗星、飘一行字，不挡画面，结算时计入累计的星星。
- **图鉴**：每种东西第一次滚起时收进图鉴（滚起时“刚滚起”会变成金色的「新收集！」），一局下来能收集几十上百种。开始页和结算页都能翻看：收集到的是会转的小模型，还有滚起过几次、多大的球才滚得起、常在哪儿；没收集到的只有剪影，提示去哪找、球要多大。一共 238 种，看看能不能集齐。

一些值得去找的东西：把广场舞音箱滚走，整个广场会安静下来；大爷们在石桌边下棋、在公园打太极；人和动物发现你能吃掉它们时会尖叫着逃跑；汽车会冲你按喇叭；城外有高铁、风车和桂林山水。

## 技术要点

- **没有任何图片、模型或音频文件，整个游戏就是一段约 1.1 MB 的脚本。** 238 种模型全部由代码拼出低多边形，文字和图案用 Canvas 现画进一张图集，音乐和音效用 Web Audio 实时合成（原创五声音阶配乐，古筝用 Karplus–Strong 拨弦算法）。球滚动本身不出声（很多休闲游戏也这样），声音交给配乐、滚起东西的「啵」声（跟着配乐的五声音阶，连滚时一级级往上走）和撞击、冲刺。
- three.js r186 + esbuild 打包内联；所有物件按类型实例化渲染，每帧逐个做视锥和距离剔除（越小的东西画得越近），远处自动换成去掉细节的低面数版本，只剩十几个像素时再换成更粗的一档（楼的窗户并成竖条，树冠变成几个八面体），阴影只画球附近的。
- 对数深度缓冲 + 随球大小缩放的镜头、阴影和雾：同一个世界里从 1 厘米的瓜子到几百米的山都能看清。
- 碰撞按物体的真实轮廓：悬空的部分（树冠、路灯横臂、雨棚）不挡路，山和小山坡按各个方向、各个高度的山坡轮廓算，大球能滚上矮的山脚，停在真正的山坡前。
- 成长速度有上限（每秒最多长大约 1.6–3%），滚雪球越滚越快但不会一下失控；物件粘在球面上随球一起长大，旧的太小了才会被“吃进去”。

## 本地构建

```bash
npm install
npm run build         # 单文件版 dist/index.html；网站版 dist/site/ 复制到仓库根目录（index.html + wanwu.<hash>.js）
npm run dev           # 不压缩的开发版，改代码自动重建
npm run gallery       # 模型图鉴：dist/gallery.html（?filter=cat 只看某类）
```

线上的 GitHub Pages 只放一个 30 KB 的页面，游戏脚本单独一个文件：国内（按时区判断）从腾讯云 COS 广州的
`wan-wu-gun-1318514885` 桶加载，github.io 在国内太慢；其他地方从页面旁边加载，任何一边失败或超过 12 秒就换另一边。
每次构建脚本名字都会变，所以发版时要把 `dist/cos/` 里压缩好的同名文件传到桶的根目录，并设置
`Content-Encoding: gzip`、`Content-Type: application/javascript; charset=utf-8`、
`Cache-Control: public, max-age=31536000, immutable`。国内的字体走 Google 自己的国内镜像 fonts.googleapis.cn。

## 目录

| 路径 | 内容 |
|---|---|
| `src/main.js` | 启动、游戏状态、主循环、结尾演出 |
| `src/game/` | 球的物理与成长、镜头、输入、地图布局与小地图、会动的东西、天空、地面、HUD、对话 |
| `src/catalog/` | 全部模型（小物件、家居、人和动物、街道、车辆、建筑、自然） |
| `src/core/` | 程序化建模工具、贴图图集、共享材质 |
| `src/audio/` | 合成器、乐器、配乐、音效 |
| `docs/CATALOG_GUIDE.md` | 建模规范（坐标约定、API、风格、面数预算） |
